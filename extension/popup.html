プライバシー

本拡張には、利用者の情報を開発者へ送信する機能はありません。

操作した BOOTH ページの商品情報・購入情報を、同じ PC の VRCLibMan に送ります。アプリへ送れない場合は JSON ファイルとして保存します。

ページの読み込みや商品説明の補完で BOOTH に通信します。パスワードや Cookie はアプリへ送りません。

ペアリングコードと設定はブラウザ内に保存し、拡張の削除で消せます。書き出した JSON とアプリに送った情報は、拡張を削除しても残ります。
