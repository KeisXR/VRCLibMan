# 購入した対応版

商品の対応範囲（product_avatars）、購入した対応版、アバター本体の所持は独立して扱う。設定の「対応表を編集」は別名と共通素体の編集であり、今回の変更対象ではない。

## 判定

Rust の purchased_editions::Catalog が、購入済みバリエーションと自分用の購入履歴にあるバリエーション名を、既存の名前解決で照合する。購入履歴を読み込んでいない無料配布・受け取ったギフトも、ライブラリの購入済みバリエーションから判定できる。色・サイズや商品説明だけでは購入版を推定しない。

「フルセット」「全対応版セット」「全アバターセット」「fullset」「allavatars」と明確に一致するバリエーションは、商品の対応範囲に従う。判定できないセットや1版で複数アバターに対応する商品は手動で設定する。

## 保存と編集

DB版13で purchased_editions 表を追加する。自動判定は元データから毎回計算し、手動指定だけを独立した表に保存する。モードは auto（購入情報から判定）、specific（個別の対応版）、all（商品の対応範囲に従う）、unknown（対応版未設定）。all はアバター一覧を固定しないので、対応追加に追従する。個別版は追従しない。

商品カードの「分類を編集」で、商品の対応範囲と購入した対応版を別々に編集する。検索は名前と別名を対象にし、所持アバターのみ・選択済みのみで絞れる。検索・絞り込みを切り替えても選択を保持する。リストを内部スクロールさせ、保存・キャンセルを下端に表示する。設定の対応表は変更しない。

手動設定は再インポート・再分類でも保持する。変更は既存の商品更新と同じトランザクションで保存する。対応版の設定によって本体所持は変えない。

## 表示・件数

ライブラリの商品数は従来どおり商品単位。アバター詳細の通常一覧には、購入した対応版のある商品を表示する。商品の対応範囲に含まれるがその対応版を買っていないアバターへは、共通素体経由でも件数を広げない。

対応版未設定の商品はライブラリに残し、対象アバターの「対応版未設定」に折りたたんで表示する。通常の対応アセット件数には含めない。商品カードにも対応版未設定の印を出し、手動設定への既存の導線を維持する。

## データ移行

ZIP形式を版4にし、purchasedEditionsに商品IDごとの手動設定を含める。自動判定結果は、移行先で元データから再計算する。購入履歴・金額・既存の対応範囲は書き換えない。ZIPの読み込み自体は従来どおり未実装。
