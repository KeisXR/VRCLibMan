## 内蔵ブラウザのログイン状態と権限の見直し（2026-11-20）

対象はブランチ `claude/eloquent-gauss-wu42w3`。Linux のコンテナ（Ubuntu 24.04、WebKitGTK 2.52）で、テストと見本の画面だけを確かめた。実際の WebView（WebView2、WKWebView、WebKitGTK）での動作は確かめていない。

### 読んで確かめたこと（変えていない）

- Cookie を Rust が読むのは、本人が押した 1 件のダウンロードだけである（`quiet::session_header`）。対象は `https://booth.pm/downloadables/<番号>` で、最初の要求にだけ付け、転送先には付けない。ヘッダは記録・イベント・データベースに出ない。

### 直したこと

- **開いたサイトの記録が残る。** `booth-browser.log` はどのサイトでも読み込みのたびに origin を残し、「閲覧データを削除」では消えなかった。削除のときに、未対応カテゴリの行以外を消す。
- **機能をオフにすると削除のボタンが消える。** ログイン状態は端末に残るのに、消す手段が画面から無くなっていた。プロファイルが残っていればボタンと理由を出す。
- **ページからの権限の要求に応答を決めていなかった。** wry 0.57 は、応答の指定が無いと macOS でカメラとマイクの要求を許可で返す（`wry_web_view_ui_delegate.rs`）。カメラ・マイク・位置情報・通知・画面共有・MIDI・センサーを拒否にした。クリップボードの読み取りと保護された動画は WebView の既定のままである。
- **確認用 WebView がダウンロードを保存できた。** 保存せず、新しい窓も開かないようにした。機能をオフにして閉じるとき、macOS で常駐する確認用も捨てる。
- **Linux のプロファイルのフォルダが既定の権限だった。** Cookie が平文で入るので 0700 にする。既にあるフォルダも次に使うときに直す。
- **全取得と購入履歴は、ページ自身の申告だけで着いたと判断していた。** ページを読む前に、タブの本当のアドレスが同じ BOOTH のホストであることを確かめる。アドレスを読めないときは従来どおり進める。
- AGENTS.md は macOS のログアウトを `clear_all_browsing_data` と `remove_data_store` と書いていたが、実装は `remove_data_store` だけである。記述を実装に合わせた。

## アセット更新の保存を表へ移す（2026-11-20）

対象はブランチ `claude/eloquent-gauss-wu42w3`。Linux のコンテナ（Ubuntu 24.04、WebKitGTK 2.52）で確かめた。Windows と macOS では実行していない。

### 変えたこと

- アセット更新の対象・観測・履歴は、`settings` の 1 行（`asset_update_watch_v1`）に JSON でまとめて入っていた。全商品を対象にすると 1000 商品で 16.5MB になり、更新確認は商品 1 件ごとにこの全体を読み、解析し、書き直していた。そのあいだデータベースのロックを持つので、ほかの画面の読み込みが待たされる。
- DB版15 で、商品ごとの行（`asset_watch`）と履歴（`asset_watch_history`）に分けた。全体の設定（自動確認、全商品、再試行までの時刻、世代）だけを `settings` の `asset_update_state_v2` に置く。確認 1 件で書くのは、その商品の 1 行と、変化があったときの履歴 1 行だけである。
- 説明文は「変わったかどうか」にしか使っていないので、全文ではなくダイジェスト（FNV-1a 64 ビット）を保存する。古い値を移すときも同じ文字列から同じダイジェストを作るので、基準は引き継がれる。
- 古い値が JSON として読めないときは、そのキーを残して対象なしで始める。ライブラリを開けなくしないため。もう無い商品の行は移さない。
- ライブラリ全取得のあとの記録は、商品ごとの書き込みを 1 回のコミットにまとめた。

### 確かめたこと

- `cargo test --lib --features tauri/custom-protocol`：556 件成功。版 14 のライブラリを開くと版 15 になり、対象・無効にした商品・基準が残ること、旧キーが消えること、全商品の許可を広げないこと、履歴が 200 件で切れること、1 件の確認で書く行が 1 行だけであることをテストにした。
- 合成した 1000 商品（全商品が対象）で、保存値は 16.5MB から 0.1MB になった（`nav_bench`、デバッグビルド）。

### 確かめていないこと

- 実際のライブラリでの移行（数 MB の旧値を持つ `library.sqlite`）。
- Windows と macOS でのビルドとテスト。
- 更新確認を最後まで回したときの時間と、確認中の画面の体感。
