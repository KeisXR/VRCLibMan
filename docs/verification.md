## 今後の記録方法

配布前の確認では、対象コミット・アプリと拡張の版・OS・端末構成・実施日・手順・結果を記録してください。見本、テスト、実機で確かめた範囲を区別します。

- 分類規則: 新しい一時 DB、サンプル、必要に応じた実ライブラリ。実商品の本文や年齢制限のある本文は記録へ貼らない。
- 拡張と内蔵ブラウザ: ログイン済みライブラリの商品数、全取得と中止、ログイン切れ、ギフト、公開商品ページ。
- 配布物: Windows / Apple Silicon Mac でインストール、起動、サムネイル、ファイル移動・コピー、バックグラウンド動作。
- 更新: 署名付き次版を使った実インストーラでの更新、ライブラリ・設定の引き継ぎ、失敗時の再試行。手順と自動テスト範囲は [配布とアプリ内更新](updater.md) を参照。

見本データの画面が動くことは、名前解決やファイル照合の正しさの証明にはなりません。Rust の規則テストと実機確認を、それぞれの範囲の証拠として扱います。
