# VRCLibMan

BOOTH で入手した衣装・髪・小物を、アバターごとに探せるデスクトップアプリです。商品情報と手元のファイルを結び付け、ワールドもまとめて管理できます。データと分類処理は端末内で扱います。

**[ダウンロード（GitHub Releases）](https://github.com/KeisXR/VRCLibMan/releases) · [画面付きの使い方ガイド](how-to-use.md)**

| 環境 | 配布物 |
| --- | --- |
| Windows x64 | `VRCLibMan_<version>_x64-setup.exe` |
| Apple Silicon Mac・macOS 14 以降 | `VRCLibMan_<version>_aarch64.dmg` |
| Chrome / Edge 拡張 | `vrclibman-booth-export-<version>.zip` |

Windows 版は未署名です。Mac 版に Apple の正式な署名・公証はありません。OS の警告が出る場合があります。Intel Mac 向けの配布物はありません。Windows 10 では WebView2 が別途必要になる場合があります。

## はじめる

1. Releases からアプリをインストールします。Mac はアプリを「アプリケーション」へ移してください。
2. 分類に [Ollama](https://ollama.com/) を使う場合は、同じ PC にインストールして起動します。推奨モデルは `qwen3.5:9b`（メモリ 16 GB 以上が目安）、軽量な選択肢は `qwen3.5:4b`（8 GB 以上が目安）です。対応する Mac では Apple のオンデバイスモデルを選べ、Ollama の追加導入は不要です。
3. 初回セットアップで分類用モデルと BOOTH の読み込み方を選びます。
4. 「インポート」から商品情報を読み込み、分類します。ダウンロード済みのファイルがある場合は、ライブラリフォルダを指定して商品と結び付けます。

商品情報の読み込みと、商品のファイルのダウンロードは別の操作です。分類結果や対応アバターはあとから修正できます。詳しい手順とモデルの動作目安は [使い方ガイド](how-to-use.md) にあります。

### BOOTH の読み込み方

- **Chrome / Edge の拡張機能（既定）**: 普段のブラウザで開いた商品ページや購入ライブラリをアプリへ送ります。購入ライブラリを読む場合は、ブラウザで BOOTH にログインしてください。
- **内蔵ブラウザ（任意）**: アプリ専用のウィンドウで BOOTH にログインし、商品情報を読み込みます。読み込んだ商品は「アセット」やアバター詳細で探せます。ログイン後は、未ダウンロードの購入済みファイルを商品カードから 1 件ずつ取得できます。初期状態では無効です。[ファイル取得の手順](how-to-use.md#内蔵ブラウザのログインを使ってファイルを取得する)

拡張を使う場合は、Releases の拡張 zip を展開し、Chrome / Edge の拡張機能管理画面で開発者モードを有効にします。「パッケージ化されていない拡張機能を読み込む」から `manifest.json` があるフォルダを選び、アプリの設定に出るペアリングコードを拡張へ保存してください。[詳しい導入手順](how-to-use.md#拡張をインストールしてつなぐ)

## データと通信

本アプリと拡張には、利用者の情報を開発者へ送信する機能はありません。

- 商品情報・分類・対応表・設定は端末内に保存します。分類には、同じ PC の Ollama または対応する Mac の Apple オンデバイスモデルを使います。
- 拡張はパスワードや Cookie をアプリへ送りません。内蔵ブラウザのログイン状態は端末内に保存し、選んだファイルの取得に使用します。「内蔵ブラウザの閲覧データを削除」で、内蔵ブラウザ内の全サイトのログイン状態と閲覧データを削除できます。ライブラリ情報・設定・ブックマークは残ります。
- サイトの閲覧・商品情報や画像の読み込み・ファイルのダウンロードでは、BOOTH などの取得先と通信します。モデルの取得、対応表やアプリの更新時にも外部と通信します。
- アプリデータは Windows の `%APPDATA%\app.vrclibman.desktop`、macOS の `~/Library/Application Support/app.vrclibman.desktop` に保存します。アンインストールしても自動では削除しません。[バックアップ手順](how-to-use.md#13-データの保存とバックアップ)

「ダウンロードを自動整理」は初期状態ではオフです。有効にすると、自分で開始した対象ファイルをダウンロードフォルダから指定したライブラリフォルダへ移します。バックグラウンド動作とログイン時の起動も、必要な場合だけ設定で有効にできます。

保存・通信・削除の案内は、アプリの「設定 → データ → プライバシー」と、拡張の「プライバシー」でも確認できます。通信方式の技術情報は [開発ガイド](docs/development.md#通信と受信口) にあります。

## 利用規約とアカウントへの注意

VRCLibMan は BOOTH / pixiv / VRChat の非公式アプリです。購入履歴の読み込みやログイン状態を使ったファイルの取得は、サービスの利用規約や運営の判断によって制限される可能性があります。**規約への適合や、アカウントの制限・停止が起きないことは保証しません。** 使用前に [BOOTH ガイドライン](https://booth.pm/guidelines) と [pixiv / BOOTH の利用規約](https://policies.pixiv.net/) を確認してください。

BOOTH へのアクセス間隔は初期値の **1 秒を推奨**します。0.25 秒はアクセス制限やサーバー負荷のリスクが高い設定で、変更時に確認が必要です。間隔にかかわらず、BOOTH 側の制限が優先されます。一括・無人の自動ダウンロードや、年齢確認の自動通過は行いません。

## 既知の制限

- BOOTH のページ構造やログイン手順が変わると、読み込みが動かなくなることがあります。
- 分類や対応アバターの判定は誤ることがあります。「確認」から修正してください。登録されていない素体関係は推測しません。
- 非公開・公開終了・年齢確認が必要な商品の説明を取得できない場合があります。読み込みが途中で止まった場合は、ログイン状態などを確認して再実行してください。
- 内蔵ブラウザのログイン状態は端末内に残ります。共有 PC では使用後にアプリ内からログアウトしてください。
- Unity への導入や商品の購入は行いません。リモートライブラリは共有フォルダとのファイルコピー機能です。設定で「リモートへ自動同期」を有効にすると、アプリ起動中に登録済みの手元のファイルを約1分ごとにコピーします。同名ファイルの上書きや削除、リモートからの自動取得は行いません。

## 更新

アプリは「設定 → データ → アプリの更新」から確認・ダウンロードし、「再起動して更新」で適用できます。サイドバーにも進捗を表示します。起動時の確認は設定でオンにしたときだけ（既定はオフ）で、定期的な更新確認は行いません。署名を検証できないファイルは適用せず、ライブラリと設定は引き継ぎます。v0.1.7 以前にはアップデータがないため、対応版を一度手動でインストールしてください。

拡張は別途、Releases の新しい zip を展開し、ブラウザの拡張機能管理画面で読み込み直してください。
